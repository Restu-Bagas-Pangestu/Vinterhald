# Hold Vinterhald

Prototype permainan membangun kota bertema fantasi Nordik (low-poly 3D, berjalan langsung di browser).

## Cara bermain
Buka halaman GitHub Pages repositori ini, atau buka `index.html` di browser.

- Seret untuk menggeser peta, gulir untuk zoom, Q/E untuk memutar kamera.
- Pilih bangunan di menu bawah lalu klik petak kosong di peta.
- Klik warga untuk melihat datanya dan membuat kamera mengikutinya.
- Simpanan permainan tersimpan otomatis di browser (localStorage).

## Teknologi
Satu berkas HTML dengan three.js r128 (cdnjs) dan Google Fonts. Tanpa proses build.
